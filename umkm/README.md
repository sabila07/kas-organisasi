# UMKM Kita — Tampilan Awal

Versi ini adalah **prototipe antarmuka**: beranda dan menu navigasi sudah disiapkan, tetapi belum menyimpan data usaha dan belum terhubung ke server.

## Menu yang tersedia

- Beranda dan ringkasan usaha
- Transaksi
- Produk & stok
- Pelanggan
- Utang & piutang
- Laporan
- Modal usaha
- Karyawan
- Pengaturan

Angka pada dashboard hanya data ilustrasi. Jangan gunakan untuk pembukuan nyata.

## Pratinjau

Buka `index.html` di browser, atau sajikan folder ini melalui HTTPS untuk mencoba mode PWA.

## APK Android

Konfigurasi Capacitor tersedia di folder ini. Alur GitHub Actions ada di `.github/workflows/build-umkm-apk.yml`; jalankan workflow dari cabang `umkm-ui-prototype` untuk membangun APK debug. APK debug hanya untuk pengujian awal.
